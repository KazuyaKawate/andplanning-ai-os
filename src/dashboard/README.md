# Dashboard — AIカンパニーの見える化

AI社員たちが今なにをしているか、事業とSNSの数字がどうなっているかを、1画面で見るためのダッシュボードです。

## 開き方

`index.html` をブラウザで開くだけです(ビルドやサーバーは不要です)。

```bash
open src/dashboard/index.html        # macOS
# または
python3 -m http.server -d src/dashboard 8000   # → http://localhost:8000
```

## 画面の中身

| 場所 | 内容 |
| --- | --- |
| 上の帯 | 時計、終わった仕事・いま働いているAI・今日の投稿・社長の作業時間、24時間の出動グラフ |
| 数字のパネル | SNSの数字(YouTube / Threads / Instagram / X / TikTok)、今月の売上と目標達成率、問い合わせ、案件数、つないでいる道具(MCP) |
| 組織図 | 社長 → AI CEO(Claude Code)→ 各部署(Factory)。AI CEOとレビュー役(Codex)は相互レビューでつながっています |
| 下の帯 | AI社員どうしのやりとりの流れ |

- **☀ Day / ☾ Night** で、黄色のポップなテーマと暗いネオン風のテーマを切り替えられます(選んだテーマは覚えておきます)。
- **⏸ 動きを止める** で、動きを一時停止できます。
- スマホの幅では縦に並ぶレイアウトに変わります。

## 書き換え方

表示される社員・部署・数字は、すべて `data.js` にまとめてあります。

- 部署を増やす: `departments` に1つ追加します(`color` でレーンの色が決まります)
- 社員の状態: `status` を `working`(作業中)/ `done`(できた!)/ `review`(確認中)/ `idle`(待機)のどれかにします
- 数字: `sns` と `business` の値を書き換えます

> いまの数字と状態の変化は**サンプル(シミュレーション)**です。`app.js` の `tick()` がランダムに状態を進めています。
> 本物のデータにつなぐときは、`tick()` の代わりにAPIやスプレッドシートから値を読み込み、`renderDynamic()` を呼び出してください。

## ファイル

- `index.html` — 画面の骨組み
- `style.css` — 見た目(Day / Night の2テーマ、レスポンシブ対応)
- `data.js` — 表示するデータ(ここを書き換える)
- `app.js` — 描画、線の描画、時計、シミュレーション
