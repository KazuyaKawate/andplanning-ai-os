## 1. 形式の特徴

- **静止画の漫画コマ + パン/ズーム + 声優のボイス + 吹き出し** で見せる「漫画動画」。アニメーションは最小限で、カメラワークとエフェクトで動きを出している。
- 語りは **主人公の一人称ナレーション**（「俺の名前は〇〇。〇〇だ」）。ナレーションは四角い枠、キャラのセリフは吹き出し、と役割を分けている。
- 連載形式。冒頭で前話を数十秒で振り返り、最後は次回予告で締める。

## 2. タイムライン（構成と尺）

| 区間 | 時間 | 尺 | 比率 | 役割 | 画面 | 音 |
|---|---|---|---|---|---|---|
| ① フック + 前回まで | 0:00–0:48 | 48秒 | 5% | 一人称の名乗り → 状況説明 → 敵の紹介 | 群衆の引き絵 → 対立の構図 → 敵幹部の顔見せ | 暗めの BGM、フラッシュ転換 |
| ② 事件・苦戦 | 0:49–2:19 | 1分30秒 | 9% | 主人公がピンチに陥る | 縦長コマ、分割コマ、斜め分割のアクション | 打撃・斬撃 SE、画面揺れ |
| ③ 強キャラ登場 → 無双 | 2:20–5:47 | 3分27秒 | 21% | 「ため → 爆発」で一気にカタルシス | 登場の中央アップ → 顔の超アップ → 大技 | 咆哮で色反転フラッシュ、骨折 SE、悲鳴 |
| ④ 回想（過去と贖罪） | 5:48–10:35 | 4分47秒 | 29% | 脇役を深掘りして感情移入させる | セピア/彩度を落としたビネット、ゆっくりパン、クロスフェード | ピアノ・弦の BGM に切り替え |
| ⑤ 日常・絆 | 10:36–12:09 | 1分33秒 | 9% | 「戦争が終わったら〇〇しよう」で未来を約束（後の展開の伏線） | 事務所の温かい場面、スライドインの立ち絵 | 穏やかな BGM |
| ⑥ 本筋に戻る → 罠 | 12:10–15:57 | 3分47秒 | 23% | 「話は〇〇へ戻る」で現在に戻し、最大のピンチへ | 走る主人公と地図を見る脇役の分割、罠、落下物 | 速い切り替え、長い地鳴り・揺れ（15:37–15:56） |
| ⑦ 引き（クリフハンガー） | 15:58–16:25 | 27秒 | 3% | 回想した脇役が助けに来る、で終える | 傷ついた主人公 → 青いオーラの登場カット | 曲のクライマックス |
| ⑧ アウトロ | 16:26–16:38 | 12秒 | 1% | 定型のチャンネル紹介 + 次回予告の帯 | キャラ一覧 + 下部の帯（次回の日付・あおり文） | エンディング BGM |

**構成のポイント**
- 「アクション → 回想（感情） → アクション → 引き」のサンドイッチ型。回想が全体の約3割で最も長い。
- 回想で深掘りした人物が、最後のカットで「命をかけて助けに来る」。**回想 = 最後の引きの伏線** として設計されている。
- 回想への入り方：現在の場面で人物が走り出す → 体の古傷（息が苦しい）をきっかけに過去へ。戻り方：「話は〇〇へ戻る」という定型ナレーション。

## 3. 吹き出し・テロップのルール

| 種類 | 形 | 使う場面 | 位置 | タイミング |
|---|---|---|---|---|
| ナレーション枠 | 白い四角（縦書きが多い）、黒文字・黒フチ | 一人称ナレーション、状況説明 | 画面の端（右上・左下など）でキャラにかぶらない | ナレーションの読み始めと同時に表示し、読み終わりまで残す |
| 通常のセリフ | 白い楕円の吹き出し | 会話 | 話者の近く | 声の出だしと同時に表示、約3〜5秒 |
| 叫び・怒号 | ギザギザ（爆発形）の吹き出し、特大の太字 | 咆哮、決めゼリフ | 画面中央 | 声と同時に出し、ズーム・揺れ・フラッシュを重ねる |
| 内心・ささやき | 小さめの吹き出し / 点線 | 含み笑い、独り言 | 話者の近く | 短く2〜3秒 |
| 狂気・異常 | 語尾を伸ばす・カタカナ混じり（「〜ヨ！」「ワカラナイ！」） | 狂ったキャラ | — | 表記で異常さを出す |
| 次回予告の帯 | 画面下の横帯 | アウトロ | 下部 | 最後の約12秒 |

- 吹き出しは **声が出るのと同時に出して、言い終わったらすぐ次へ**。1つの吹き出しを長く残さない。
- 長いセリフは「…」で2〜3個の吹き出しに分けて、テンポを保つ。

## 4. 効果演出のルール

| きっかけ | 演出 |
|---|---|
| 打撃・衝突 | 横方向の画面揺れ + 白フラッシュ + 打撃 SE（ドカッ） |
| 刃物・斬撃 | スウッシュ SE + 斜めの分割コマ |
| 咆哮・豹変 | 顔の超アップへパンチイン → 色反転（シアン/緑系）のフラッシュ → 爆発形の吹き出し |
| 残虐な決め技 | 骨折 SE（ボキッ）+ 血しぶきのオーバーレイ + 群衆の悲鳴 SE |
| 回想に入る | BGM をピアノ/弦に切り替え + セピア・低彩度・ビネット + ゆっくりパン + クロスフェード |
| 温かい日常 | 穏やかな BGM + 立ち絵のスライドイン |
| 同時に進む2つの場面 | 画面分割で素早く切り替え |
| 大崩落・クライマックス | 長めの地鳴りと揺れ（約20秒）+ 金属の崩落 SE（ガシャーン） |
| 救世主の登場 | 青いオーラ / 光のエフェクト + 中央の光る吹き出し + 曲のサビ |

## 5. テンポの数値

- コマの切り替え：**2〜4秒ごと**（静止画でも、パンやズームを加えて止まって見えないようにしている）。
- アクションの区間は2秒前後で速く、回想は4秒以上でゆっくり。
- ズームやパンチインは「決めゼリフ・咆哮・打撃」のときだけ使い、多用しない。

## 6. AIOS への学習ポイント（And Planning 向け）

- **Video Factory の雛形**として [templates/manga-video-template.md](../templates/manga-video-template.md) に一般化した。台本 → コマ割り → 吹き出し → 効果のタイムラインを、この型で自動生成する。
- 演出を「きっかけ（ナレーション・セリフ・打撃・回想）→ 決まった演出」のルール表にしてあるので、台本にタグを付ければ編集指示書（EDL）に機械的に変換できる。
- vidIQ の `video_transcript`（タイムスタンプ付き）と `video_watch`（映像分析）の組み合わせで、他の参考動画も同じ形式で分析・保存できる。
