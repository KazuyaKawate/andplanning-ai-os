## 一言まとめ

ひとり起業の唯一の弱点「忙しすぎる」を、Claude Code で作る **AI 社員** が解消した。
やることは **①売れる商品を決める → ②ナレッジを貯める → ③YouTube で集客する** の3ステップ。
AI 社員の賢さは「貯めたナレッジの質」で決まる。

## 1. ひとり起業のメリットとデメリット

**メリット**
1. **固定費が小さい** → 目先の売上に追われない。合わない客を断れ、長期視点の経営ができる（コーチングでも受講前に審査して断っている）。
2. **時間と場所に縛られない** → 平日休み・安い時期の旅行などを自分で決められる。
3. **意思決定が早い** → 会議・稟議が不要。思いついた2日後には新事業を動かせる。

**デメリット**
- 集客・経理・サポート・事務をすべて1人でやるので、とにかく忙しい（仕事に終わりがない）。

**ゲームチェンジ：AI 社員**
- 資料作成・リサーチ・X の下書き・売上/受講生の進捗集計などを AI 社員に任せる（寝ている間に完了）。
- 人間の社員は月30万円前後、AI 社員は月3万円程度。採用コスト・社会保険なし、24時間稼働、修正依頼にも嫌な顔をしない。
- 難易度のたとえ：AI 以前の年商1000万は「エベレスト登頂」、今は「ハーフマラソン」。

## 2. STEP1：売れる商品を決める（何屋かを決める）

- 「売れる商品がない」は普通。多くは **持っていないのではなく、市場ニーズを見極める目がないだけ**（体感7割）。
- 事例
  - 60代男性 × AI 活用 → 若手ばかりの AI 発信の中で「60代向け AI 活用」は空白地帯。
  - 元プロのサッカー経験者 → 子ども向け教室ではなく「強豪校に通う子の **親** のサポート（食事・メンタル）」に切り口を変えて、120万円を売り上げた。
- 目の育て方は2つ：**商品を持つ人と関わる機会を増やす** ＋ **市場の全体像を把握する**（誰が何にいくら払っているか）。
- 商品が浮かばない人は **クライアントワーク系の副業** から。特に **動画編集** がおすすめ：発信者の「企画 → 集客 → LINE 誘導 → 販売」を横で見ながら、お金をもらって学べる。

## 3. STEP2：ナレッジを貯める

AI 社員は「ハーバード卒の新入社員」。優秀でも会社のことを知らなければ活躍できない。
→ 自分の経験・ノウハウ・考え方・過去の仕事・競合・クライアント情報を **AI が読める形で1か所のフォルダ** に集める（本人は Obsidian を使用）。
→ 「副業テーマで台本1万字」「基礎講座を作って」「勉強会の資料を作って」と頼むだけで、フォルダを参照した自分らしい成果物が出てくる。

**貯め方3つ**
1. **NotebookLM × Claude Code 連携で市場情報を集める**
   - 役割分担：大量の情報の要約は NotebookLM、考えるのは Claude Code（Claude Code に大量リサーチさせるとトークンを浪費して精度が落ちる）。
   - 例：「英語コーチングの競合を集めて NotebookLM 経由で分析。価格帯・対象者・レビューの褒め/不満を HTML で」
   - 例：「『Claude Code 副業』の直近の5分以上の動画20本を分析。伸びている動画のタイトルの共通点・冒頭の入り方・コメント欄の悩みを出典付き HTML で」
   - 出力は HTML にすると図入りで見やすい。音声入力（Aqua Voice など）で作業が体感5倍速くなる。
2. **自分が喋ったことを録音・録画する**
   - 移動中の思いつき・面談・添削をボイスレコーダー（Plaud / スマホのボイスメモ）で記録し、文字起こしをナレッジフォルダへ。
   - 口調や思想を AI が学べる。「受講生に毎回指摘していることをまとめて勉強会資料に」→ 2行の指示で完成。
3. **貯める作業自体をルーティン化（定期実行）**
   - Claude Code の定期実行で「時間・やること・保存先」を指定する。
   - 例：「毎週月曜7:30に1週間分の録音/録画を文字起こしし、内容ごとにフォルダ保存」
   - 本人の運用：3日に1回 競合リサーチ＋伸びている動画の冒頭リサーチ／月1で売上集計と受講生の進捗まとめ／面談録画の文字起こしが毎日たまる。

## 4. STEP3：集客は YouTube 一択

1. **難しいから** — 簡単な副業（AI で有料 note の量産・塗り絵・AI 美女など）はすぐレッドオーシャン。YouTube はリサーチ・企画・台本・撮影・編集・サムネ・分析と参入障壁が高く、やり切る人が少ない。
2. **再現性が高いから** — Instagram/X は見た目や影響力など小手先の要素が大きい。YouTube は発信の質とわかりやすさが正当に評価される（筋トレと同じで、やれば成果が出る）。
3. **積み上がるから** — ストック型なので、過去動画から毎日 LINE 登録が入る（広告なし）。長尺で人柄と専門性が伝わるので、相談前に信頼ができていて売り込みが不要になる。

## 5. AIOS への学習ポイント（And Planning 向け）

- **Memory System が中核**：AI 社員の品質はナレッジの質で決まる。本リポジトリの `docs/memory/` を「1か所のナレッジフォルダ」として育てる。
- **Research Factory**：「大量収集 = NotebookLM 等の要約系 / 判断 = Claude」の役割分担を Workflow Engine の設計に取り込む。出力は HTML レポートを標準にする。
- **Workflow Engine の定期実行**：競合リサーチ・伸びている動画の分析・録音の文字起こし・売上集計を cron 化し、ナレッジが自動でたまる仕組みにする。
- **Video / Marketing Factory**：集客の主軸は YouTube（ストック型）。動画の transcript を Memory に取り込む今回の流れ（vidIQ → 要約 → docs/memory）自体を定型ワークフロー化できる。
- **Creator / Writing Factory**：台本・講座・勉強会資料は「ナレッジ参照 + 短い指示」で生成するのを基本形にする。
- **商品設計の型**：「強み × 意外な切り口（年代・顧客の周辺者）」で空白地帯を探す。
