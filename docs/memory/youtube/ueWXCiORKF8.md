## 一言まとめ

実績ゼロの初心者は、自分の商品を作るより **A8.net のアフィリエイト** から始めるのがよい、という主張。
Threads で A8 リンクが使えるようになったので、**Claude に変数付きプロンプトで紹介文を3パターン作らせ → Threads に投稿 → 返信欄（スレッドに追加）に A8 リンク＋「PR」表記** という流れを実演している。

## 1. なぜ初心者に A8.net なのか（3つの理由）

1. **売る商品を自分で作らなくていい** — note やコンテンツ販売は「何を売るか」で9割が止まる。A8 には企業が広告費を出している既存商品が美容・健康・金融・転職などジャンル別に揃っている。
2. **お金がかからない** — 登録無料、スマホ1台で始められ、在庫も仕入れもない。売れなくても赤字にならない。
3. **資産になる** — 投稿やページが残り、寝ている間も報酬が発生しうる。季節に合わせて紹介先を入れ替えれば収益が途切れにくい。

## 2. 実践手順

### A8.net 側
1. A8.net にメディア会員として無料登録する（メール登録 → 会員情報 → 完了）。
2. 「プログラム検索」でカテゴリから案件を探す。おすすめは健康・美容・ファッション、お金系の発信者なら金融・投資・保険・不動産・転職。
3. 案件の詳細で次を必ず確認する。
   - **成果報酬額**（例：骨盤ケア商品で新規購入1件6,400円）
   - **成果条件**（初回利用のみ、注文後30日以内の入金 など）
   - **PR 文**（企業が想定するターゲットや訴求の強み。プロンプトの入力に使える）
4. **提携申請** をする。多くの案件は承認後でないとリンクを取得できない。新規アカウントでも通るものは多い。

### Claude 側（紹介文の生成）
1. A8 用の投稿プロンプト（本体は動画の LINE 特典で、本メモには含まない）を貼り付ける。
2. **変数** を埋めて送る：**ジャンル / ターゲット / 紹介したい商品 / 口調**
   - 例：健康 / 20〜50代のデスクワークで姿勢が悪い男性 / 骨盤ケアサポーター / 丁寧
   - ターゲットは A8 の PR 文をそのまま使う。
3. 訴求軸が違う **3パターン** が返ってくる。
   - A：価格訴求（「1日あたり約66円」「整体に毎回5,000円払う人は試して」）
   - B：時短・手軽さ（「ストレッチ15分 → つけるだけ1分」）
   - C：他の商品との比較（「色々試した人へ」）※価格などは商品に合わせて直す必要あり
4. 1つ選んでコピーする（1分以内で投稿が完成する、とのこと）。

### Threads 側（投稿）
1. 本文に貼り付ける。改行したい行にはスペースを1つ入れる。
2. 「スレッドに追加」（返信欄）に A8 のアフィリエイトリンクを貼り、**「PR」表記** をつけて投稿する。

## 3. 主張・マインドセット部分

- 「途中まで見て自己流でやると1円も稼げない」。投稿が見られない、クリックされても売れない原因は、才能ではなく最初の設計のずれ。
- A8 × Claude × Threads は今が先行者利益の時期で、半年後には皆がやっている、という煽り。
- 動画の後半は LINE 登録（無料講座・個別勉強会・特典）への誘導が中心。

## 4. AIOS への学習ポイント（And Planning 向け）

- **Writing / Marketing Factory のプロンプト設計の型**：「固定のプロンプト本体 + 変数（ジャンル / ターゲット / 商品 / 口調）」→「訴求軸の違う3パターンを出す（価格・時短・比較）」。AIOS の投稿生成ワークフローの標準テンプレートにできる。
- **入力ソースの自動取得**：ターゲットや訴求は A8 の「PR 文」「成果条件」から取れる。Research Factory で案件情報を取り込み → 変数を自動で埋める → 3案生成、という流れにすれば人の作業は「選ぶ・投稿する」だけになる。
- **Compliance チェックを Workflow に組み込む**：「PR」表記（ステマ規制）、健康系の表現（薬機法・景表法：「骨盤が正しい位置に」などの効能表現）、成果条件との整合を、投稿前の自動チェック項目にする。
- **1本目（NmHuq95jHXs）との対比**：前の動画は「自分の商品 × YouTube（ストック型）」、今回は「他社の商品 × Threads（フロー型）」。フロー型は投稿数を回す必要があるので、AI 生成と定期実行（自動化）との相性がいい。
