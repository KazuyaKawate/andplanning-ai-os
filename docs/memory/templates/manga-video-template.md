# 漫画動画 演出雛形（v1）

参考：[ヒューマンバグ大学「【狂人】守若の兄貴…ルイス虐殺！」の分析](../youtube/FTtJ6B0Fg4s.md)
対象：一人称ナレーション + 静止画の漫画コマ + 声 + 吹き出しで見せる、10〜20分の物語動画（連載型）。

使い方：`{ }` を埋めて台本を作り、台本の各行に **タグ** を付ける。タグごとに §3・§4 の演出を当てれば、そのまま編集指示書になる。

---

## 1. 構成テンプレート（尺の目安：全体16分の場合）

| # | パート | 目安の尺 | 比率 | 書くこと | 画面 | BGM |
|---|---|---|---|---|---|---|
| 1 | フック + 前回まで | 0:00–0:50 | 5% | 「俺の名前は{主人公}。{立場}だ」→ {現在の対立}を1〜2文で → {今回の敵}を顔見せ | 引きの絵 → 対立の構図 → 敵のアップ | 緊張感のある BGM |
| 2 | 事件・苦戦 | 〜2:20 | 9% | {主人公}が{状況}で押される。敵の正体がつかめない | 縦長コマ、分割コマ | アクション BGM |
| 3 | 強キャラ登場 → 無双 | 〜5:50 | 21% | {強キャラ}が登場 → ため（息を吸う・目つき）→ 爆発（咆哮）→ 大技 → 周りが逃げる | 中央に登場 → 顔の超アップ → 大技 | 盛り上がる BGM |
| 4 | 回想 | 〜10:35 | 29% | 現在の{脇役}の行動/古傷をきっかけに過去へ → {過去の過ち} → {恩人}の言葉 → 立ち直り | セピア・ゆっくりパン | ピアノ/弦 |
| 5 | 日常・約束 | 〜12:10 | 9% | {脇役}が仲間を支える日常 →「{戦いが終わったら〇〇しよう}」という約束（伏線） | 温かい室内、立ち絵 | 穏やか |
| 6 | 本筋に戻る → 最大の罠 | 〜16:00 | 23% | 「話は{場所}へ戻る」→ 手がかり → 移動 → 罠 → 最大のピンチ | 分割、罠、崩落 | 速いテンポ → 地鳴り |
| 7 | 引き | 〜16:25 | 3% | ピンチの主人公 → **回想した{脇役}が助けに来る** → 決めゼリフで終わる | 光/オーラの登場カット | 曲のサビ |
| 8 | アウトロ | 最後の約12秒 | 1% | 定型のチャンネル紹介 + 次回予告の帯「次回 {日付} {あおり文}」 | キャラ一覧 + 下部の帯 | エンディング |

**構成ルール**
- サンドイッチ型：アクション（約35%）→ 回想・日常（約38%）→ アクション（約23%）→ 引き。
- 回想で深掘りした人物を、必ず最後の引きで動かす（回想 = 引きの伏線）。
- 回想への入り：現在の行動・体の傷・持ち物をきっかけにする。戻り：「話は〇〇へ戻る」という定型句を使う。
- 最後は解決させずに、救出に来た瞬間で切る（次回へ引っ張る）。

## 2. 台本タグ

| タグ | 意味 | 例 |
|---|---|---|
| `[N]` | 一人称ナレーション | `[N] 俺の名前は{主人公}。` |
| `[S:キャラ]` | 通常のセリフ | `[S:A] 何してんの？` |
| `[SHOUT:キャラ]` | 叫び・決めゼリフ | `[SHOUT:A] 全員まとめてかかってこい！` |
| `[IN:キャラ]` | 内心・ささやき・笑い | `[IN:敵] クククク…` |
| `[HIT]` `[SLASH]` | 打撃 / 斬撃 | 直前のセリフのあとに置く |
| `[REVEAL]` | 正体が明かされる・強キャラ登場 | |
| `[FB-IN]` `[FB-OUT]` | 回想に入る / 回想から戻る | |
| `[SPLIT]` | 同時に進む2つの場面 | |
| `[QUAKE]` | 崩落・大災害 | |
| `[HERO]` | 救世主の登場 | |
| `[NEXT]` | 次回予告の帯 | |

## 3. 吹き出し・テロップの仕様

| タグ | 形 | 位置 | 出すタイミング | 表示時間 |
|---|---|---|---|---|
| `[N]` | 白い四角（縦書き）、黒文字・黒フチ | 画面の端（キャラにかぶらない） | 読み始めと同時 | 読み終わりまで（1枠2〜4秒、長文は分割） |
| `[S]` | 白い楕円の吹き出し | 話者の近く | 声の出だしと同時 | 3〜5秒 |
| `[SHOUT]` | ギザギザの爆発形、特大の太字 | 画面中央 | 声と同時 | 2〜4秒（揺れ・フラッシュを重ねる） |
| `[IN]` | 小さめ / 点線 | 話者の近く | 声と同時 | 2〜3秒 |
| `[NEXT]` | 下部の横帯 | 画面下 | アウトロの頭 | 最後まで |

- 1つの吹き出しは長くても2行。長いセリフは「…」で区切って2〜3個に分ける。
- 狂ったキャラは語尾を伸ばしたりカタカナを混ぜたりして、表記で異常さを出す。

## 4. 効果演出の仕様

| タグ / きっかけ | 映像 | 音 |
|---|---|---|
| コマの切り替え（標準） | 2〜4秒ごとにカット。静止画には必ずゆっくりパンかズームを付ける | — |
| `[HIT]` | 横揺れ 0.3〜0.5秒 + 白フラッシュ 1〜2フレーム | 打撃 SE |
| `[SLASH]` | 斜めの分割コマ + 斬撃ライン | スウッシュ SE |
| `[SHOUT]` | 顔の超アップへパンチイン → 色反転フラッシュ（シアン/緑系） | 叫びの声を大きく |
| 残虐な決め技 | 血しぶきのオーバーレイ | 骨折 SE + 群衆の悲鳴 |
| `[REVEAL]` | 中央に配置 → ゆっくりズームイン | BGM のアクセント |
| `[FB-IN]` | クロスフェード + セピア/低彩度 + ビネット、パンを遅く | BGM をピアノ/弦に切り替え |
| `[FB-OUT]` | 色を元に戻すフラッシュ転換 | アクション BGM に戻す |
| `[SPLIT]` | 2分割の画面で素早く交互に切り替え | — |
| `[QUAKE]` | 長めの地鳴りと揺れ（15〜20秒）+ 落下物 | 軋む音 → 崩落 SE |
| `[HERO]` | オーラ/光のエフェクト + 中央の光る吹き出し | 曲のサビ |

**使いすぎないルール**：パンチイン・色反転・爆発形の吹き出しは `[SHOUT]` `[HIT]` `[REVEAL]` のときだけ。1分あたり2〜3回までに抑えて、ここぞの効果を保つ。

## 5. テンポの目安

| 区間 | 1コマあたり | 演出の密度 |
|---|---|---|
| アクション（2・3・6） | 約2秒 | 揺れ・SE が多い |
| 回想・日常（4・5） | 4秒以上 | ゆっくりパン、クロスフェード中心 |
| 引き（7） | 3〜4秒 | 1カットを長めに見せる |

## 6. 台本の例（形式だけの見本）

```
[N] 俺の名前は{主人公}。{組織}の{立場}だ。
[N] 目下、俺たちは{敵組織}と{対立}の最中。
[S:敵] {敵の挑発}
[N] だが、いざ踏み込むと{予想外の状況}だった。
[IN:敵] クククク…
[SLASH]
[S:主人公] 待てコラァ！
[REVEAL] [S:強キャラ] {登場の一言}
[SHOUT:強キャラ] {決めゼリフ}
[HIT]
[FB-IN] [N] {脇役}には消せない過去があった。
...
[FB-OUT] [N] 話は{場所}へ戻る。
[QUAKE]
[HERO] [SHOUT:脇役] {救出の決めゼリフ}
[NEXT] 次回 {日付} {あおり文}
```

## 7. AIOS での使い方（Video Factory）

1. Writing Factory で `{ }` を埋めた台本をタグ付きで生成する。
2. タグを §3・§4 の表に当てて、編集指示書（時間・画面・吹き出し・効果・SE/BGM）に変換する。
3. 尺は §1 の比率で配分する（10分なら各パートの尺を比率どおりに縮める）。

> 型は他チャンネルの分析から抽出したもの。絵・キャラ・セリフ・設定は自分のオリジナルを使うこと。
