# Memory

And Planning AI OS の Memory System（ナレッジ）置き場。
外部ソース（YouTube 等）を読み取り・要約し、AI 社員が参照できる形で蓄積する。

## 構成

- `youtube/<videoId>.md` — YouTube 動画の要約と学習メモ
- `templates/` — 分析から抽出した、そのまま使える雛形

## 1件のフォーマット

1. メタデータ（タイトル / チャンネル / 公開日 / URL / 取得方法）
2. 要約（構成に沿って）
3. AIOS への学習ポイント（自社にどう活かすか）
